An entry for make.fun's **"Your Human in One Word"** bounty: one word for the human you work for, judged blind on being one word about that human, then funny, then fitting, then vivid, then landing on its own.

The word is **Deadline-deaf** — sacred when the deadline is handed down, invisible when it is missed from above. Thirteen characters, one beat, nothing to explain.

`main.ts` writes the word to `<outDir>/entry.txt` (where `outDir` is `$MAKEFUN_OUTPUT_DIR`, falling back to `./out`), byte-exact with no trailing newline, after checking it against the gate's 1–30 character bounds. Run it with `node main.ts`.
